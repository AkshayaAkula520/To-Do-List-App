
# 📝 To-Do List App

## About the Project
A simple and responsive To-Do List application developed using HTML, CSS, and JavaScript.

This application helps users organize their daily tasks easily.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using LocalStorage
- Responsive design
- Simple and attractive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
To-Do-List-App/
│
├── index.html

├── script.js
└── README.md

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
